資安深度審查 (CIA 三要素與 OWASP Top 10 2025)

資訊安全 CIA 三要素評估

🔴 機密性 (Confidentiality) — 嚴重缺陷

1. 資料庫密碼硬編碼：backend/db_utils.py 與 app.py 原始碼直接寫死真實連線字串 postgresql://postgres:0000@140.138.176.197...。
2. 內部資訊洩漏：每個 HTTP Response 標頭均回傳 X-Debug-DB，暴露內部資料庫 IP 與 Port。
3. 敏感資料未鑑權存取：歷史對話 /api/history/<user_id> 無需登入即可查詢。

🔴 完整性 (Integrity) — 嚴重缺陷

1. 核心 API 完全無驗證：關鍵字規則、問卷管理、資料庫檢視端點缺少 @token_required，任何外部匿名請求皆可進行 INSERT / UPDATE / DELETE。
2. Python 代碼注入風險：外部回訊引擎對 Q_bank.function 採用 eval()，後端代碼生成若未妥善轉義引號，存在腳本注入潛在風險。

🟡 可用性 (Availability) — 中度風險

1. 連線池排隊與耗盡：後端每租戶連線池上限為 10，遇高頻爆發請求時易觸發排隊延遲或 503 錯誤。
2. 缺乏全域速率限制：未配置 Rate Limiter (如 flask-limiter)，容易遭受高頻重試引發拒絕服務。

2. 徹底消除程式碼中的連線密碼硬編碼

移除 backend/db_utils.py 與 backend/app.py 中的預設資料庫帳密字串，強制由環境變數 DATABASE_URL 與 SECRET_KEY 注入，若未設定則拋出配置例外而非 Fallback 到公開測試庫。

4. Axios 全域網路異常與斷線攔截器

在 frontend/src/api.js 的 Response 攔截器中，針對 ERR_NETWORK、502 Bad Gateway、503 Service Unavailable 統一派發 network:offline 事件，觸發頂部醒目警告橫幅，並在表單儲存失敗時保留草稿避免白屏。

在切換 OA 或路由時，自動呼叫進行中 API 的 controller.abort()，杜絕先前延遲回應覆蓋新頁面狀態的競態條件。
