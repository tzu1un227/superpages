## 1. 概述
本設計基於 FRD 和 FS，聚焦於簡潔、響應式和直觀的用戶體驗。使用 React + Material-UI，支援桌面和手機。整體風格：簡明現代，無特定品牌。顏色：主色灰白 (#FFFFFF 背景)，主色藍 (#2196F3)，輔色黑 (#000000)。

## 2. 主要頁面設計

### 2.1 登入頁面
- **佈局**：居中卡片，頂部標題 "Line-Bot 資訊視覺化系統"。
- **元件**：
  - Google OAuth 按鈕（大尺寸，帶 Google 圖標）。
- **UX**：點擊 Google 按鈕後，跳轉至 Google 進行認證。成功返回後，應用程式會自動使用 Google 提供的資訊向後端驗證。若該 Google 帳號已預先登記在系統中，則成功登入並跳轉至儀表板；若未登記，則在頁面上顯示錯誤提示：「此帳號未被授權，請聯繫管理員」。
- **Mockup 描述**：單欄佈局，移動端適應。

### 2.2 普通用戶登入後頁面
- **佈局**：若無權限，顯示空白頁面 + 訊息 "請連絡管理員設置權限"。若有權限，直接進入對應 OA 的儀表板。
- **UX**：自動跳轉，無手動選擇。

### 2.x 頂部導航列 (AppBar)
- **位置**：頁面最上方，固定顯示。
- **左側**：Logo / 系統名稱 / 側邊欄收合按鈕 (漢堡選單)。
- **中間**：**帳號切換下拉選單** (僅當用戶擁有多個 OA 權限時顯示，用於切換當前數據檢視範圍)。
- **右側**：用戶頭像 / 登出按鈕。

### 2.3 用戶人數和加入趨勢儀表板頁面 (FR-002)
- **佈局**：側邊欄（左側，收合式）+ 主內容區（右側）。
- **側邊欄**：
  - 導航：用戶趨勢儀表板、回應趨勢儀表板、分群管理。
  - **(移除)**：帳號切換移至頂部。
  - 過濾器：時間區間下拉（週/月/年）、分群下拉（從遠端載入）。

### 2.6 管理員頁面 (新頁面)
- **佈局**：僅管理員可見，側邊欄顯示 "系統管理" 入口。頁面內部分為兩個分頁 (Tabs)：「用戶管理」與「網站設定」。
- **分頁 1：用戶管理**
  - **列表**：Gmail、角色、授權 OA。
  - **操作**：新增用戶 (輸入 Gmail)、編輯權限 (勾選 OA)、刪除用戶。
- **分頁 2：網站設定 (OA Configs)**
  - **列表**：OA 名稱、Page ID、DB URL。
  - **操作**：新增設定、編輯設定、刪除設定。
- **UX**：操作後即時更新列表。普通用戶不可見此頁面。
- **Mockup 描述**：使用 Material-UI Tabs 切換內容。

## 3. 用戶流程
1. 註冊：Google OAuth → 郵件連結驗證（包含隨機字串token，點擊後後端重定向成功頁面自動完成） → 登入。
2. 普通用戶：登入 → 若無權限顯示訊息；若有，進入儀表板。
3. 管理員：登入 → 用戶管理頁面編輯權限 → 進入儀表板。
4. 儀表板：選擇頁面 → 過濾 → 查看圖表 → 匯出。
5. 分群：切換子頁面 → 從遠端載入群組 → 編輯 → 顯示更新按鈕 → 確認發送至遠端或回復。

## 4. 非功能設計
- **無障礙**：鍵盤導航，螢幕閱讀器支援。
- **錯誤處理**：全局錯誤提示（Toast）。
- **載入**：Skeleton 載入狀態。
- **樣式**：簡明，無複雜動畫。
